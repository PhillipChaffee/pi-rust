# pi-rust

Rust port of [earendil-works/pi](https://github.com/earendil-works/pi) (MIT,
Copyright (c) 2025 Mario Zechner): an AI coding agent with a terminal UI,
provider layer, and RPC protocol.

Status: bootstrap skeleton. The port plan (crate boundaries mirroring
`packages/*`, runtime, TUI approach, protocol compatibility) is tracked in
this repo's issues; see AGENTS.md for agent rules and the reference codebase
location.
